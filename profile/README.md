# Glyphex

Cookieless, privacy-first web analytics. No consent banner, no personal data, no third-party lookups.

- **[glyphex-tracker](https://github.com/glyphexio/glyphex-tracker)**: the MIT-licensed script that runs on your site. 1.6 KB core, modules only when you turn them on.
- **[glyphex-wordpress](https://github.com/glyphexio/glyphex-wordpress)**: the official WordPress plugin.

Try it: [glyphex.io](https://glyphex.io) · [Live demo](https://glyphex.io/demo) · [Docs](https://glyphex.io/docs) · [Changelog](https://glyphex.io/changelog)
