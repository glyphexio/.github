# Contributing

Thanks for helping.

- Bugs and ideas: open an issue with steps to reproduce.
- Pull requests: keep them small and focused. For the tracker, run `npm run build` and include the size change from `dist/sizes.json` in the description. CI fails the build if the core is 2,000 bytes gzipped or larger.
- Privacy first: changes that collect more data about visitors need a strong reason and will get extra review.
